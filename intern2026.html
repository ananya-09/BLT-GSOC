BLT-Toasty

Cloudflare-native AI triage with fail-closed disclosure safeguards.

BLT-Toasty is a Cloudflare-native AI triage assistant that automates the processing of OWASP vulnerability reports. To maintain strict responsible disclosure standards, Toasty enforces a fail-closed PII redaction gate using Microsoft Presidio before any AI processing occurs. The system provides token-optimized LLM summarization, embedding-based duplicate detection via Cloudflare Vectorize, and structured MCP export for agent-driven automation.

BLT-MCP

Model Context Protocol tooling and workflows for BLT contributors.

BLT-MCP is an MCP integration layer for OWASP BLT that enables AI agents and MCP-compatible clients such as Claude Desktop and Cursor to interact with BLT through structured tools and resources. The project focuses on contributor onboarding, issue discovery, workflow assistance, and safe human-in-the-loop write operations rather than unrestricted automation.
